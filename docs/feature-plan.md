# 功能增强计划表

## 第一阶段：纪念日提醒 + 情侣聊天 + 地图打卡

### 1.1 纪念日倒计时提醒
- **前端**：Dashboard 添加纪念日倒计时卡片，支持临近提醒弹窗
- **后端**：新增提醒通知表 `Notification`，存储提醒类型、时间、状态
- **定时任务**：服务端定时检查即将到期的纪念日，生成提醒
- **所需支持**：无（纯数据库 + 前端实现）

### 1.2 情侣实时聊天
- **技术方案**：WebSocket（Socket.io 或原生 WebSocket）
- **前端**：聊天页面，支持文字、表情、图片消息
- **后端**：消息表 `Message`，WebSocket 服务端
- **所需支持**：
  - 需要部署环境支持 WebSocket（Vercel 不支持，需换 Railway/Fly.io/自建服务器）
  - 图片消息需要云存储支持（见 3.2）

### 1.3 地图打卡
- **前端**：集成地图 SDK（高德/百度/Mapbox），标记约会地点
- **后端**：新增 `CheckIn` 表（经纬度、地点名、备注、照片）
- **功能**：足迹地图、地点收藏、打卡统计
- **所需支持**：
  - 地图 API Key（高德地图或百度地图）
  - 可选：图片存储

## 第二阶段：AI 深度集成

### 2.1 AI 日记自动生成
- 根据当日心情、打卡地点、天气自动生成日记草稿
- 用户确认后写入日记表

### 2.2 AI 约会智能推荐
- 输入预算、时间、偏好，AI 生成 3 个约会方案
- 集成天气 API 获取当日天气
- **所需支持**：天气 API Key（和风天气/OpenWeatherMap）

### 2.3 AI 矛盾调解
- 引导双方分别表达感受（"我感到...因为我需要..."）
- AI 分析双方输入，给出中立建议
- 前端设计分步表单交互

### 2.4 AI 周/月报
- 聚合心情趋势、互动频率、愿望完成率
- AI 生成关系健康报告，给出改善建议
- 前端设计报告展示页面

### 2.5 AI Agent 工具调用增强
- Agent 可创建纪念日、愿望、日记（已有基础）
- 新增：创建聊天消息草稿、创建地图打卡
- Agent 记忆关联：记住用户偏好用于推荐

## 第三阶段：内容与回忆

### 3.1 情侣时间轴
- 聚合所有事件（日记、心情、纪念日、愿望、打卡、照片）
- 按时间倒序展示，支持筛选和搜索
- 前端设计瀑布流或时间线布局

### 3.2 情侣相册（需云存储）
- **功能**：图片上传、相册分类、照片关联事件
- **技术方案**：接入云存储（阿里云 OSS / 腾讯云 COS / AWS S3 / Supabase Storage）
- **所需支持**：
  - 云存储服务的 API Key 和 Bucket 配置
  - 图片上传：前端直传或后端代理
  - 图片处理：缩略图生成（可选：Sharp 或云服务自带处理）
- **数据库**：扩展现有 `Photo` 表，新增 `Album` 表

### 3.3 电子情书/卡片
- 模板系统：预设多款情书模板（手写风、简约风、复古风）
- 支持自定义文字、背景、字体
- 生成图片可分享
- **所需支持**：字体文件（手写字体），或使用 Canvas/SVG 渲染

### 3.4 情侣歌单
- 创建共享歌单，添加歌曲链接
- 支持网易云音乐/QQ 音乐链接解析
- **所需支持**：音乐平台 API（可选，也可手动添加链接）

---

## 所需你提供的信息

| 序号 | 项目 | 说明 | 必要性 |
|------|------|------|--------|
| 1 | **云存储服务** | 阿里云 OSS / 腾讯云 COS / Supabase Storage / AWS S3，用于图片上传 | 相册功能必需 |
| 2 | **地图 API Key** | 高德地图或百度地图 Web 服务 Key | 地图打卡必需 |
| 3 | **天气 API Key** | 和风天气或 OpenWeatherMap Key | AI 约会推荐需要 |
| 4 | **WebSocket 部署环境** | 当前 Vercel 不支持 WebSocket，需换 Railway/Fly.io/自建 | 聊天功能必需 |
| 5 | **手写字体文件** | 用于电子情书模板（可选，可用系统字体替代） | 可选 |
| 6 | **音乐平台 API** | 网易云/QQ 音乐（可选，可手动添加链接） | 可选 |

---

## 建议实施顺序

1. **纪念日倒计时**（无需额外支持，纯前后端）
2. **情侣时间轴**（无需额外支持，聚合现有数据）
3. **AI 功能集成**（日记生成、约会推荐、周报）
4. **地图打卡**（需地图 API Key）
5. **情侣相册**（需云存储）
6. **情侣聊天**（需 WebSocket 环境）
7. **电子情书**（需字体文件或用系统字体）
8. **情侣歌单**（可选）
